## 🌟 What is PRAGYA?

**PRAGYA** is a self-evaluating, multi-step AI agent that:

## 🏗 Architecture Overview

```
User Goal
   ↓
Planner Agent
   ↓
Tool Router
   ↓
Search | Calculate | Generate
   ↓
Critic Agent
   ↓
Refinement (if needed)
   ↓
Aggregator
   ↓
Final Structured Report
```

Each layer has a defined responsibility.

## 🧠 How It Works (Step-by-Step)

### 1️⃣ User Enters a Complex Goal

Example:

> "Create a 30-day marketing plan for an AI SaaS."

---

### 2️⃣ Planner Agent Decomposes Goal

Outputs structured steps:

* Conduct market research → `search`
* Estimate budget → `calculate`
* Draft marketing copy → `generate`

---

### 3️⃣ Tool Routing

Switch node directs each task to the correct execution tool.

---

### 4️⃣ Execution Layer

🔎 Search → Real web data
🧮 Calculate → Deterministic JS logic
✍ Generate → LLM-based structured content

---

### 5️⃣ Critic Agent (Self-Evaluation)

Each output is scored:

* Score ≥ 7 → Accept
* Score < 7 → Trigger Refinement

Quality is enforced automatically.

---

### 6️⃣ Final Report Generator

Generates:

📌 Executive Summary
📌 Step-by-Step Outcomes
📌 Key Decisions
📌 Final Deliverable

## 📦 Setup Instructions

### 1️⃣ Import Workflow

Import `pragya-workflow.json` into n8n.

### 2️⃣ Configure Credentials

Create:

* OpenAI credential
* Serper credential

Add your API keys locally.

### 3️⃣ Activate Workflow

Enable webhook and deploy.

### 4️⃣ Connect Frontend

Send POST request to:

```
https://your-n8n-instance/webhook/pragya
```
